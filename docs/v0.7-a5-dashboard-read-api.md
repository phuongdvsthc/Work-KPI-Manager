# v0.7-A5: Unified Authenticated Dashboard Read API

**Project:** School Task & KPI Management (STHC Work + KPI)  
**Milestone:** v0.7 – Dashboard & Reporting Experience  
**Version:** v0.7-A5  
**Status:** Unified Authenticated Dashboard Read API  

---

## 1. Overview

This document specifies the unified authenticated backend Read API (`GET /api/dashboard/reporting`), which exposes the existing internal orchestration service (`dashboardReportingService`) while automatically enforcing role-based reporting scope and security validation.

---

## 2. API Endpoint Specification

- **Route:** `GET /api/dashboard/reporting`
- **Method:** `GET`
- **Authentication:** Required (`authenticateUser` middleware via `Authorization: Bearer <token>`).
- **Read-Only Guarantee:** Produces no database writes or side effects.

---

## 3. Supported Query Parameters

- `date_from` (YYYY-MM-DD)
- `date_to` (YYYY-MM-DD)
- `organization_unit_id` (UUID)
- `employee_id` (UUID)
- `source_id` (UUID)
- `metric_id` (UUID)
- `kpi_id` (UUID)
- `status` (String status filter)

Any unlisted query parameters (e.g. `role`, `viewer_user_id`, `is_system_wide`) are strictly rejected with status `400`.

---

## 4. Role Behavior

- **Staff / Viewer:** Receives only personal dashboard and organization membership scope. Cannot request other employees or unauthorized units.
- **Manager:** Receives data for permitted primary and descendant organizational units and associated employees.
- **Admin:** Receives approved system-wide reporting scope (all active units and employees).
- **Executive / BGH:** Receives approved system-wide read-only reporting scope.

---

## 5. HTTP Status Behavior

- `200 OK`: Successful aggregation.
- `400 Bad Request`: Invalid filters, invalid date range, malformed UUIDs, or unknown query parameters.
- `401 Unauthorized`: Missing or invalid authentication token.
- `403 Forbidden`: Inactive user, unknown role, or unauthorized scope escalation attempt.
- `500 Internal Server Error`: Unexpected failure (sanitized, no stack traces or raw database errors exposed).
