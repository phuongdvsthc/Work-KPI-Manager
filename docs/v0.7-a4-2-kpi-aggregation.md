## 1. Overview

This document specifies the read-only KPI aggregation service (`dashboardKpiAggregationService`) implementing:
1. Reusable aggregation of KPI assignments, items, and scoring results.
2. Source selection rules distinguishing live assignments (using live scoring resolver and manual actual entries) versus official locked assignments (using authoritative reviews and official snapshots).
3. Multi-dimensional breakdowns (by period, definition, employee, organization unit, and status).
4. Chronological time series grouped by KPI period.
5. Strict permission and role scoping across Staff, Manager, Admin, and Executive/BGH roles.

## 3. KPI Source Selection Rules

- **Active / Draft / Non-locked Assignments**: Evaluated using live scoring logic (`resolveLiveScoresBatch`) querying actual entries and applying defined scoring methods and targets.
- **Locked / Closed Assignments**: Evaluated using official review records and official snapshots (`resolveOfficialScoresBatch`).
- **No Double Counting**: Live and locked assignments are processed into separate batches and never mixed or double-counted.
