## 1. Overview

This document specifies the frontend foundation for the Staff personal Dashboard (`v0.7-B1`), providing typed API client integration, routing, the page shell, reporting period filters, loading/empty/error states, and a responsive layout foundation.

---

## 2. Actual Staff Dashboard Route

- **Route Hash:** `#/staff-dashboard` (and `#/overview` for authenticated users with `system_role === 'staff'`).
- **Protection:** Protected by existing authentication (`AuthProvider` / `authenticateUser` backend route guards).

## 4. API Client & Supported Filters

- **Endpoint:** `GET /api/dashboard/reporting`
- **Supported Staff-Safe Filters:**
  - `date_from`
  - `date_to`
  - `source_id`
  - `metric_id`
  - `kpi_id`
  - `status`
- **Security Constraints:** Does not send `role`, `viewer_user_id`, `employee_id` for other users, organization scope, or `is_system_wide`.

---

## 5. UI States & Behaviors

- **Loading State:** Displays a clean loading spinner and status message without rendering fake numbers.
- **Empty State:** Displays a clear Vietnamese message when data is empty for the selected period while keeping filters accessible.
- **Error State:** Displays a safe Vietnamese error message with a retry action and preserves current filters.
- **Partial Response:** Non-blocking warning banner when partial data is returned by the backend.
