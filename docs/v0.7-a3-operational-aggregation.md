## 1. Overview

This document specifies the read-only core operational aggregation services implementing:
1. **Task Summary Aggregation**: Deduplicated task metrics, status counts, overdue tracking, and completion rates.
2. **Daily Report Summary Aggregation**: Attendance work-mode breakdowns, expected vs submitted days, and multi-source deduplication.
3. **Attention Summary**: Unread notifications and unacknowledged announcements.
4. **Operational Warnings**: Stable machine-readable warning builders.
5. **Combined Orchestrator**: Unified reporting response adhering to v0.7 contracts.

## 3. Counting & Deduplication Rules

- **Tasks**: Tasks owned or assigned are deduplicated by task ID to prevent owner/collaborator overlap double-counting. Completed tasks are never marked overdue. Tasks without due dates are tracked separately. (`due_soon_tasks` is set to 0 as no pre-existing threshold/window was defined in v0.7-A1 contract).
- **Daily Reports**: Multiple source submissions for an employee on a single date are deduplicated into a single attendance/reporting day. Work modes (`onsite`, `remote`, `off`, `business_trip`) are accurately tallied. (`low_reporting_completion` warning was removed as no valid threshold source existed in v0.7-A1).
- **Attention Items**: Read-only counters for unread notifications and pending required acknowledgements. Has zero write side effects.
- **Warnings**: Stable machine-readable codes (`overdue_tasks`, `missing_daily_reports`, `pending_required_acknowledgements`).
