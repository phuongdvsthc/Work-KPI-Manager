## 1. Overview

This document specifies the read-only metric aggregation service (`dashboardMetricAggregationService`) implementing:
1. Aggregation of stored metric entries according to their defined aggregation types (`sum`, `avg`, `min`, `max`, `latest`, `count`).
2. Robust scope enforcement across Staff, Manager, Admin, and Executive/BGH roles.
3. Multi-dimensional breakdowns (by date, source, employee, organization unit, and metric definition).
4. Time-series extraction and data quality warning codes.

## 3. Aggregation Rules & Constraints

- **Aggregation Methods**: Supports `sum`, `avg`, `min`, `max`, `latest`, and `count` based on `metric_definitions.aggregation_type`.
- **Percentages**: Percentage metrics avoid invalid additive summation unless supported.
- **Scope Isolation**: Staff access personal metrics only; Manager access permitted unit/descendant metrics; Admin and Executive/BGH follow system-wide scopes (read-only for Executive).
- **Warnings**: Stable machine-readable codes (`metric_data_unavailable`, `metric_unsupported_aggregation`).
